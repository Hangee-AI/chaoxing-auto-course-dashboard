# 超星学习通 GUI 版

一个给 [Samueli924/chaoxing](https://github.com/Samueli924/chaoxing) 套上图形界面的 Windows 版本，不用敲命令行，双击就能刷课。

基于原项目源码改造，核心刷课逻辑完全复用原项目，只新增了图形界面、课程/章节勾选和实时进度显示。

> 本项目仅用于学习交流，请勿用于盈利。使用前请阅读文末的免责声明。

## 功能

- **图形界面，双击启动**：不用配置命令行参数，不显示黑色控制台窗口
- **两级勾选**：先选课程，展开后还能精确选择要刷的章节（视频 / 文档 / 测验所在的具体章节）
- **已完成自动识别**：已完成的章节置灰、默认不勾选
- **实时进度**：正在学习的章节会标注「← 学习中」，结束后标注「√ 完成 / × 失败」，底部状态栏显示视频进度条
- **随时停止**：任务执行中点「停止」即可中断
- **扫码/账号登录**：支持手机号 + 密码登录，也支持复用 `cookies.txt` 免密登录
- **兼容题库**：目录下放 `config.ini` 并配置 `[tiku]` 后，章节检测会自动答题
- 保留原项目的命令行入口 `main.py`，两种用法互不影响

## 快速开始

### 方式一：双击运行（Windows，推荐）

1. 安装 [Python 3.10+](https://www.python.org/downloads/)，安装时勾选 **Add Python to PATH**
2. 双击文件夹里的 **`点我运行.bat`**
3. 首次运行会自动安装依赖，耐心等待几分钟
4. 界面打开后：填手机号密码 → 点「登录并获取课程」→ 勾选课程/章节 → 点「开始学习」

> 如果双击后没有任何反应，请在文件夹空白处右键 →「在终端中打开」，执行 `python gui.py`，这样能看到具体报错。

### 方式二：手动安装

```bash
git clone https://github.com/你的用户名/你的仓库名.git
cd 你的仓库名
pip install -r requirements.txt
python gui.py        # 启动图形界面
```

其他系统（macOS / Linux）同样可以 `python gui.py`，但 `点我运行.bat` 仅适用于 Windows。

## 使用说明

1. **登录**
   - 勾选「使用 cookies 登录」时会优先读取根目录的 `cookies.txt`，即使不填密码也能登录
   - cookies 失效时会提示失败，取消勾选后用手机号密码登录即可（登录成功会自动刷新 `cookies.txt`）

2. **选择学习内容**
   - 课程前面的 ▶ 点开可加载该课程所有章节
   - 点击文字可切换勾选状态；「全选 / 全不选」可批量操作
   - 已完成的章节显示为灰色，默认不勾选

3. **开始学习**
   - 「开始学习」按钮要等登录成功、课程列表加载完成后才会变亮
   - 日志区实时输出运行信息，蓝色进度条显示在底部状态栏

## 命令行版

原项目的命令行用法仍然可用：

```bash
python main.py                                  # 交互式输入账号密码
python main.py -c config.ini                    # 使用配置文件
python main.py -u 手机号 -p 密码 -l 课程ID1,课程ID2  # 全部参数走命令行
python main.py -h                               # 查看全部参数
```

## 配置与题库

配置文件由 `config_template.ini` 复制为 `config.ini` 得到，常用项：

- `[common]` `username` / `password`：账号密码
- `[common]` `speed`：视频倍速（1 ~ 2）
- `[common]` `notopen_action`：遇到未开放章节时 `retry` 重试 / `continue` 跳过
- `[common]` `add_learning_count` / `target_count`：是否刷章节学习次数
- `[tiku]` `provider`：题库，支持 `TikuYanxi`、`TikuGo`、`TikuLike`、`TikuAdapter`、`AI`、`SiliconFlow`、`TikuManual`，多个题库可用英文逗号分隔做回退
- `[tiku]` `submit`：是否自动提交章节检测（`false` 时只保存答案，需自行登录提交）

各项的详细说明都写在 `config_template.ini` 的注释里。

## 常见问题

**「开始学习」是灰色的点不了**
需要先点「登录并获取课程」，等课程列表出现后按钮才会变亮。若登录报错，日志区会显示原因。

**双击 `点我运行.bat` 没反应**
多半是依赖没装好或 Python 路径问题。右键文件夹 →「在终端中打开」→ 执行 `python gui.py` 查看报错信息。

**提示 cookies 失效**
取消勾选「使用 cookies 登录」，用手机号密码重新登录一次。

**刷课中途被要求验证码**
同一账号不要同时开多个程序（例如命令行版和界面版同时跑），适当降低并发章节数（`jobs`）和倍速。

**能刷哪些任务点**
视频、音频、文档、阅读、章节检测（测验）、直播，取决于课程实际布置的任务点类型。
